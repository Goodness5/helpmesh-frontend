# Accessibility checklist

Built into the app: skip link, one h1, landmarks, visible focus, 48px targets, labels, error summary, live status, reduced motion, text size, high contrast, and plain copy.

Not done yet, so these stay open:

- [ ] VoiceOver or NVDA pass on every screen
- [ ] Keyboard-only pass recorded on every screen
- [ ] 400% zoom pass
- [ ] axe on every route
- [ ] Voice-control check that the visible name matches the accessible name

Do not tick these until a person has run them.
