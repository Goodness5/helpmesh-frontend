# HelpMesh

Ask for help nearby, offer help, or fund it. Test money moves on Base Sepolia when `NEXT_PUBLIC_DEMO_MODE=false`. Set `RELAYER_PRIVATE_KEY` in `.env.local` to the deployment key. Without it, set `NEXT_PUBLIC_DEMO_MODE=true` and the app uses a demo chain labeled in the wallet.

```bash
npm run dev
npm run lint && npm run typecheck && npm test
```

Open http://localhost:3000.
